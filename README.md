# The-Ozempic-Effect

**Client question:** A fund holds $1B in consumer stocks. As weight-loss drugs like Ozempic, Wegovy, and Zepbound spread, which holdings should it trim, hold, or buy?

**Hypothesis:** Companies that depend more on snacks, sugary drinks, fast food, and alcohol fell more on major weight-loss drug news, and some of that risk is still not reflected in their stock prices.
